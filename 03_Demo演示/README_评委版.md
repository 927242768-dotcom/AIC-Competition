# 智骨云析 · AIC 评委 Demo

> 当前定位：把已训练的骨科 CT segmentation AI 转化为真实教学支架，而不是普通课程网站或科研 Dashboard。

双击 **一键启动Demo.bat** 即可。桌面程序会检查本机 `127.0.0.1:8000`，必要时调用真实项目 `D:\国创项目` 的后端后打开教学平台。

## 推荐 2–3 分钟体验顺序

1. **首页先看 AI 怎样教**：第一屏直接对照真实 Raw CT 与已保存 Prediction。学生先判断，困难时才看模型椎骨前景参考。
2. **AI 结构与空间学习**：进入“自主定位 + 分级提示”。前两级只给方向与空间关系，第三级才显示真实 segmentation prediction；点击反馈由专家 GT 椎骨前景提供参考。
3. **三平面空间核验**：在 Axial / Coronal / Sagittal 中联动十字线，把二维判断放回同一三维坐标复核。
4. **AI 连续切片导师**：先在 Raw CT 中连续追踪至少 20% 体数据范围，再解锁 Prediction，对照结构在相邻层面中的出现、变化与消失。
5. **Prediction 3D**：将同一真实 prediction 构建为 physical-space mesh，在三维中复核上下、前后、左右空间关系。
6. **AI 病例训练与纠错复盘**：病例不是资料库，而是一轮“自主判断 → 提示 → Prediction → MPR → 3D”陪练；练习答错后返回真实影像重新观察。

## 真实能力边界

- 当前正式工程模型为 **v7**，已冻结；v7.1 已完成但综合验证表现未超过 v7，因此不替换主模型。
- 主展示结果为 **v7 validation197 full-volume**，mean Dice = **0.7933**。
- 当前模型任务是 **椎骨前景二分类分割**。Prediction 不被描述成椎弓根、椎板、棘突等亚结构分类器。
- Web 优先读取磁盘中真实已有的 evaluation / prediction / GT；完整体积实时推理较慢时，不伪造“实时 AI”。
- MPR 与 3D 属于影像/几何工具；AI 的核心输出是 segmentation prediction，并被转化为分级提示、空间核验、连续切片对照与三维教学支架。
- 系统不提供自动疾病诊断、骨折识别、临床评分或学生临床能力评分。

> Research & Education Prototype：当前为医学影像教学与科研辅助原型，不替代临床诊断或医疗器械验证。
